Q28 - Fix a Supplied Page Where Overflow is Breaking Layout

Problem: Long text, wide images break layout | Solution: Overflow fixes | BCA AI

Problem 1: Long Unbreakable Text / URL

❌ BROKEN - Overflow
https://github.com/shubhisinghhh18-prog/assignment-1/blob/main/very-very-very-long-file-name-that-breaks-layout.html

Layout toot gaya, horizontal scroll aa gaya

✅ FIXED

Problem 2: Wide Image Breaking Container

❌ BROKEN - Image overflow

600px image in 320px box - Bahar nikal gaya

✅ FIXED - Image inside

Now responsive - Andar hi hai

img { max-width: 100%; height: auto; display:block; }

Problem 3: Box Sizing + Padding Overflow

❌ BROKEN - Box bigger than container
Box with width 320px + padding 30px = 380px → overflow
✅ FIXED
Box with box-sizing: border-box → stays 320px
* { box-sizing: border-box; }
max-width: 100%;

✅ Final Fixed Page Template (Copy this for your main project)

/* GLOBAL FIX FOR ALL OVERFLOW ISSUES */
* { box-sizing: border-box; }
body { overflow-x: hidden; }
img, video, iframe { max-width: 100%; height: auto; }
p, a, div { overflow-wrap: break-word; word-break: break-word; }
.container { max-width: 100%; overflow: hidden; }

/* For long content boxes */
.card { overflow: hidden; } /* or overflow: auto if scroll needed */

Teacher ko bolna: Overflow 3 reason se hota hai - 1) Long URL/text 2) Badi image 3) Padding + width. Maine sab ko max-width:100%, box-sizing:border-box aur overflow-wrap:break-word se fix kiya.

📝 Position & Z-Index Explanation (Teacher ke liye)

position: relative
.hero parent hai - iske andar absolute children position honge
.hero { position: relative; }
position: absolute
bg, overlay, shapes, badge absolute hai - relative parent ke hisab se
.hero-bg { position: absolute; top:0; left:0; }
position: fixed
Navbar fixed hai - scroll pe bhi upar rahega
.navbar { position: fixed; top:0; z-index:10; }
z-index layering
1=bg, 2=overlay, 3=shapes, 4=content, 5=badge, 10=navbar
z-index decides kaun upar dikhega

Hero Section Logic:
1. Sabse neeche image (z-index:1) → 2. Uske upar purple gradient overlay (z-index:2) → 3. Uske upar floating white circles (z-index:3) → 4. Uske upar text + card (z-index:4) → 5. Card ke upar badge NEW (z-index:5) → 6. Sabse upar fixed navbar (z-index:10)

Q33 Logic - Teacher Explanation

.product-listing {
  display:flex; /* flex container */
  flex-wrap:wrap; /* cards next line pe chale jayenge - MAIN */
  gap:20px;
  justify-content:center;
}

.product-card {
  flex: 1 1 280px; /* grow 1, shrink 1, basis 280px */
  max-width:350px; /* zyada bade nahi honge */
  min-width:260px; /* bahut chote nahi honge */
}

Desktop pe 3 cards ek row me, tablet pe 2, mobile pe 1 - automatically wrap ho rahe hain flex-wrap:wrap ki wajah se. No media query needed for wrapping, flex-basis handle kar raha hai.

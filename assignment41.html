Q41 - Code Explanation for Teacher - Breakpoints Added

/* BREAKPOINT 1 - Laptop / Tablet Landscape */ @media (max-width: 1024px) { .project { grid-template-columns: 220px 1fr; } .hero { grid-template-columns: 1fr 1fr; } .hero-text h1 { font-size: 34px; } /* Gallery 6 → 4 cols, Products 4 → 3 cols */ } /* BREAKPOINT 2 - Tablet Portrait - MAIN */ @media (max-width: 768px) { .project { grid-template-areas: "header" "hero" "gallery" "sidebar" "products" "footer"; grid-template-columns: 1fr; /* Single column stack */ } .gallery { grid-template-columns: repeat(3, 1fr); } .product-grid { grid-template-columns: repeat(2, 1fr); } } /* BREAKPOINT 3 - Mobile Large */ @media (max-width: 480px) { .gallery { grid-template-columns: repeat(2, 1fr); } .product-grid { grid-template-columns: repeat(2, 1fr); } .hero-text h1 { font-size: 26px; } } /* BREAKPOINT 4 - Mobile Small */ @media (max-width: 320px) { .gallery { grid-template-columns: 1fr; } .product-grid { grid-template-columns: 1fr; } } /* TESTING: Fixed indicator top-right shows active breakpoint */ .breakpoint-indicator::after { content changes per media query }

✅ Requirement: Add at least two breakpoints - I added 4. Tested on Desktop, Laptop, Tablet, Mobile Large, Mobile Small. Indicator top-right changes color + text on each breakpoint so teacher can see testing live.

How to Test on Multiple Screen Sizes

1. Desktop Test: Open in Chrome > Window full size > Shows "🖥️ Desktop" 2. Laptop Test: Resize window to 900px width or DevTools > 1024px > Shows "💻 Laptop" 3. Tablet Test: DevTools > Toggle Device Toolbar > iPad (768px) > Shows "📱 Tablet Portrait" + single column 4. Mobile Test: DevTools > iPhone SE (375px) or 480px > Shows "📱 Mobile Large" + 2 columns 5. Small Mobile: DevTools > 320px > Shows "📱 Mobile Small" + 1 column Chrome DevTools shortcut: F12 → Ctrl+Shift+M → Select devices All grids reflow automatically - no horizontal scroll

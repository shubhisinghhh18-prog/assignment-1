About Q43

Why Both GRID & FLEXBOX?

GRID is for 2D layouts - when you need to control both rows and columns. Like overall page, hero with 2 columns, gallery with rows and columns.

FLEXBOX is for 1D layouts - when you need to control in one direction. Like navbar (row), buttons (row), card content (column). Much simpler for components.

GRID = Page

2D, areas, template-columns, gap

FLEX = Components

1D, justify-content, align-items, gap

GRID Usage (2D Layouts)

.page { display:grid; grid-template-areas: "header" "hero" "features" "products" "footer"; }
.hero { display:grid; grid-template-columns: 1.1fr 0.9fr; }
.feature-grid { display:grid; grid-template-columns: repeat(auto-fit, minmax(280px,1fr)); }
.product-grid { display:grid; grid-template-columns: repeat(auto-fill, minmax(240px,1fr)); }
.footer { display:grid; grid-template-columns: 1.5fr 1fr 1fr 1fr; }

FLEXBOX Usage (1D Components)

.header { display:flex; justify-content:space-between; align-items:center; }
.nav { display:flex; gap:18px; }
.hero-text { display:flex; flex-direction:column; gap:16px; }
.hero-btns { display:flex; gap:12px; flex-wrap:wrap; }
.f-card { display:flex; flex-direction:column; gap:10px; }
.p-info { display:flex; flex-direction:column; flex:1; }

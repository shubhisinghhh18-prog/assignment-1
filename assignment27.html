🎨 Variant 1 - Sharp Cut

Style: Linear Gradient Background + Uneven Border Radius

This card uses border-radius: 5px 40px 5px 40px - top-left & bottom-right small, top-right & bottom-left big. Looks like a ticket / modern UI card.

Use case: For AI Course Card, Tech Card

border-radius: 5px 40px linear-gradient

💎 Variant 2 - Soft Pill

Style: Radial Gradient + Dashed Border + Full Rounded

This card uses border-radius: 30px - fully soft corners. Background is radial-gradient which starts from center.

Use case: For Profile Card, Info Card

border-radius: 30px radial-gradient dashed border

🌸 Variant 3 - Blob Shape

Style: Organic Blob Border Radius + Animated Gradient + Double Border

This uses advanced border-radius: 50% 20% 50% 20% / 20% 50% 20% 50% to create organic blob shape + animated moving gradient background.

Use case: For Creative Card, Event Card

blob radius animated gradient double border

📝 Explanation for Teacher

  • Variant 1: border-radius: 5px 40px 5px 40px + background: linear-gradient(135deg, #4a00e0, #8e2de2) - uneven corners give stylish look
  • Variant 2: border-radius: 30px + background: radial-gradient(...) + border: 4px dashed - soft + colorful
  • Variant 3: border-radius: 50% 20% / 20% 50% + background: linear-gradient with animation + border: 5px double - organic creative shape

Requirement Fulfilled: 3 different border-radius techniques + 3 different background techniques (linear, radial, animated gradient)

What I Improved (Q10 to Q14)

Earlier (Q10) was non-semantic: Used only <div> tags for everything.

Now (Q14) Improved with semantic tags:

  • <div id="header"> → <header>
  • <div class="nav"> → <nav>
  • <div class="content"> → <main> + <section> + <article>
  • <div class="footer"> → <footer>
  • Added <figure>, <figcaption>, <address>

Why Semantic Tags?

  1. Meaningful: Tag name tells purpose - header, nav, footer are self-explanatory.
  2. SEO Friendly: Google ranks semantic pages higher.
  3. Accessibility: Screen readers help blind users to navigate easily.
  4. Clean Code: Developers can read and maintain code easily.
  5. Future Proof: Modern HTML5 standard uses semantic tags.

Note: Non-semantic tags like <div> and <span> have no meaning. Semantic tags like <header> <section> have clear meaning.

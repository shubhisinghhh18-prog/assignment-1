Q37 Auto-Reflow Logic - Teacher Explanation

.product-grid {
  display:grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr)); /* KEY */
  gap:20px;
}

/* auto-fill vs auto-fit */
/* auto-fill: empty tracks bhi banata hai - grid hamesha bhara rehta hai */
/* minmax(260px, 1fr): kam se kam 260px, space bache to 1fr expand */
Desktop (1250px) 4 columns → 260px × 4 + gaps auto fit
Tablet (768px) 2-3 columns → automatically reflows
Mobile (400px) 2 columns → minmax 160px se 2 cards, no horizontal scroll
No Media Query for Columns Grid khud decide karta hai kitne columns fit honge - yehi reflow hai

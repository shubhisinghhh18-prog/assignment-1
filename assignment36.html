CSS Grid Logic - Simple Gallery (Q36 Main)

.gallery {
  display:grid; /* GRID LAYOUT */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); /* auto responsive */
  gap:15px;
}
/* auto-fit = jitne columns fit ho sake utne banenge */
/* minmax(250px, 1fr) = kam se kam 250px, zyada space ho to 1fr le lega */

Bonus - Masonry Style Gallery (grid-row span + grid-column span)

Masonry Logic

.gallery-masonry {
  display:grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows:200px;
  gap:15px;
}
.item:nth-child(1){ grid-row: span 2; } /* tall image */
.item:nth-child(4){ grid-column: span 2; } /* wide image */

First gallery simple responsive hai, second wala masonry effect ke liye span use kar raha hai. Dono pure CSS Grid se.

Q38 Named Grid Areas Logic

.dashboard {
  display:grid;
  grid-template-areas:
    "header header header"
    "sidebar main main"
    "sidebar stats stats"
    "footer footer footer";
  grid-template-columns: 240px 1fr 1fr;
  grid-template-rows: 70px 1fr auto 60px;
  gap:15px;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.stats { grid-area: stats; }
.footer { grid-area: footer; }

/* Mobile pe areas redefine */
@media(max-width:900px){
  .dashboard { grid-template-areas: "header" "sidebar" "main" "stats" "footer"; grid-template-columns:1fr; }
}

Isme naam se area define kiya hai - header, sidebar, main, stats, footer. Mobile pe same naam ko single column me stack kar diya. Yehi named grid areas ka power hai.

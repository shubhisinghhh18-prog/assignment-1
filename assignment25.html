🎨 Short Note on Design Choices

🎨 1. Color Palette

Main: Purple Gradient (#4a00e0 → #8e2de2)

Tech + Creative look deta hai. BCA AI ke liye perfect.

Background: Light gradient (#e0e7ff) - aankh par halka.

#4a00e0 #8e2de2 #f0f4ff

🔤 2. Typography

Font: Segoe UI + Arial

Clean, readable, modern. Har device pe sahi dikhta hai.

Headings: Bold + Purple + Left border se highlight.

Readable Modern

📐 3. Layout & Boxes

  • Card design with rounded corners (16px)
  • Hover pe upar uthta hai - interactive
  • Grid system - mobile pe auto-adjust
  • Top pe color border - alag alag category

🔄 4. Consistency

Ek hi style.css sab pages pe linked hai.

  • Same header, nav, footer
  • Sticky nav - scroll pe upar rahega
  • Active page yellow/purple se highlight
One CSS All Pages

♿ 5. Why Semantic?

  • SEO: Google ko samajh aata hai
  • Accessibility: Screen reader ke liye best
  • Clean Code: <header> <nav> <main> se clear meaning
SEO Semantic

✨ 6. UX Improvements

  • Box shadow + rounded corners = soft look
  • Hover animation - user ko feel aayega
  • Tag style labels for tech stack
  • Responsive grid - mobile friendly

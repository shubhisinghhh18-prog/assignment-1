Q1- Write a one-paragraph explanation of what happens between typing a URL and seeing the page. When you type a URL into your browser and press Enter, the browser first translates the human-readable web address into an IP address using the domain name system (DNS). to locate the correct server. Next, it establishes a secure connection with that server using protocols like TCP and TLS, and sends an HTTP request asking for the website's files. Finally, the server responds by sending back the HTML, CSS, and JavaScript data, which your browser quickly parses and renders into the fully interactive webpage you see on your screen.
